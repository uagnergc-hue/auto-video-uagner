Política de Privacidade

Última atualização: 17 de agosto de 2026.

Esta Política explica como o Auto Video Uagner trata dados usados para conectar e operar contas de redes sociais.

1. Dados tratados

O aplicativo pode processar identificadores de conta, tokens de acesso, tokens de atualização, IDs de páginas/canais e informações mínimas necessárias para publicar conteúdo autorizado.

2. Finalidade

Esses dados são usados exclusivamente para autenticar contas, publicar vídeos, acompanhar o status das publicações e renovar autorizações quando permitido pela plataforma.

3. Armazenamento

As credenciais são armazenadas localmente no computador do usuário e não são disponibilizadas publicamente.

4. Compartilhamento

O aplicativo não vende dados pessoais. Dados são enviados somente às plataformas necessárias para executar as ações solicitadas pelo usuário.

5. Controle do usuário

O usuário pode desconectar contas, remover credenciais e interromper a automação a qualquer momento.

6. Segurança

São adotadas medidas técnicas razoáveis para proteger credenciais e reduzir acesso indevido.

7. Retenção

Dados de autenticação permanecem armazenados enquanto a conta estiver conectada ou até serem removidos pelo usuário.

8. Contato

Para dúvidas sobre privacidade: uagnervendas@hotmail.com
